- **enkryptai-stack:** on-prem defaults that every install set by hand: the frontend sets `ON_PREM`, `NEXT_PUBLIC_VPC_FORCE_ORG_MODE` and `DEFAULT_ENTERPRISE` to `"true"` (new accounts start on the enterprise plan; the leaderboard, MCP hub and skill hub, which need Enkrypt-hosted services, are hidden), and litellm sets `HF_HUB_OFFLINE: '1'`. A VPC install that reaches Enkrypt-hosted services can set `frontend.configMap.ON_PREM: "false"`. The duplicate `DEFAULT_ENTERPRISE` key in the frontend values is removed.
