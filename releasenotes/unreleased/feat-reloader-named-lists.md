- **enkryptai-stack:** workloads no longer carry `reloader.stakater.com/auto`. Pods restart through `checksum/<name>` annotations for chart-rendered ConfigMaps and Secrets and through named Reloader lists from `global.reloadSecrets` for Secrets created outside the chart. An install that runs its own Stakater Reloader and relied on `auto` must set `global.reloadSecrets`, or restart workloads after it changes an external Secret ([#169](https://github.com/enkryptai/helm-charts/pull/169)).
