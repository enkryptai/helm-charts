- **enkryptai-stack:** gateway-kong: a failed decK sync is no longer reported as success. `kong-deck.sh` exits with the sync's exit code (it always exited 0), and also stops when it cannot check the Kong consumers. When the first sync in the `gateway-deck-sync` container fails, the container exits, so the pod never becomes Ready and `helm upgrade --wait` fails instead of leaving Kong half configured. A failed hourly re-sync is logged and retried, but does not stop the container, so a serving gateway pod stays in the Service ([onprem-install#56](https://github.com/enkryptai/onprem-install/issues/56)).
