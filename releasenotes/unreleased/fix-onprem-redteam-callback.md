- **enkryptai-stack:** red team completion callbacks reach the dashboard on-prem. The gateway's dashboard URL (`gateway-kong.configMap.gatewayEnv.DECK_APP_DASHBOARD_DOMAIN_URL`) is now `http://frontend.<release namespace>:3000`, because the short name did not resolve from the `redteam-jobs` namespace, and the red team gets the same value as `REDTEAM_CALLBACK_BASE_URL`, so it sends that callback despite the private address and attaches its dashboard credential. Without the callback, a failed run never returned its run to the user's quota. Needs a red team image that reads `REDTEAM_CALLBACK_BASE_URL` (enkryptai/sentry#675); older images ignore it. An override of the dashboard URL must set both values to the same scheme, host and port.
